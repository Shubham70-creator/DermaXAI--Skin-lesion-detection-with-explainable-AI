How to read these results

  • Classification metrics: one training run per model on one data split, so there is no estimate of seed-to-seed variation.
  • Explanation quality: 100 ISIC 2018 images; IoU between the thresholded heatmap (0.5) and the lesion mask.
  • A model-free centre-blob baseline reaches IoU 0.438 (and up to 0.473 when tuned on the same images), so IoU should be read relative to that baseline.
  • The final model had 6 more epochs than the baseline, so the comparison above does not isolate regularization alone.
  • Research prototype. Not a medical diagnosis.
